About me

I’m a full-stack web developer with a strong focus on frontend engineering, building responsive and production-ready applications with modern JavaScript and web technologies. I work across the application stack, from designing interfaces and integrating APIs to implementing backend services, data persistence, authentication, and deployment.

My development experience includes React.js, Next.js, JavaScript, TypeScript, Tailwind CSS, REST APIs, Node.js, Express.js, WordPress, PHP, MySQL, SQLite, and PostgreSQL. I use Git and GitHub for version control and collaboration, and I have deployed applications using platforms including Vercel, Render, and Neon. I also work with Figma when translating product requirements and interface designs into responsive, accessible user experiences.

I have worked both independently and within development teams, taking features from requirements through implementation, integration, testing, and deployment. My projects include full-stack applications, AI-integrated products, e-commerce platforms, business tools, and frontend applications that consume external APIs. I’m comfortable working with existing codebases, debugging issues, integrating services, and improving functionality without losing sight of the user experience.

Before moving into software development, I studied Statistics and ran my own pharmaceutical business. That experience shaped how I approach software: understand the problem first, consider the people using the product, and build solutions that are practical, maintainable, and useful beyond the initial implementation.

I’m particularly interested in opportunities where I can contribute to real products, work with experienced engineering teams, and take increasing ownership of frontend, full-stack, and application development.
